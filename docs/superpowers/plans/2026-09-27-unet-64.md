# UNet 64×64 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Con `IMAGE_SIZE = 64` la UNet aggiunge un livello esterno a 64×64 (fondo sempre 8×8, cross-attention sempre a 16×16 e 8×8); a 32 resta identica (checkpoint compatibili). Le cartelle degli esperimenti finiscono con `_32` o `_64`.

**Architecture:** In `UNet.__init__` e `forward`, due blocchi `if self.outer_level` aggiungono `down0`, `downsample0`, `upsample0`, `up0` intorno alla rete di oggi; `ValueError` se `IMAGE_SIZE` non è 32 o 64. `train.py` aggiunge `_{IMAGE_SIZE}` al nome della cartella; `make_training_gif.py` usa `runs/conditional_{IMAGE_SIZE}` come predefinita.

**Tech Stack:** Python, PyTorch 2.8, pytest 9.

**Spec:** `docs/superpowers/specs/2026-09-27-unet-64-design.md`

## Global Constraints

- Stile del progetto: docstring Args/Returns, commenti brevi in inglese sul *perché*, solo l'essenziale, nessun ciclo generico sui livelli.
- A `IMAGE_SIZE = 32` i moduli della UNet e i loro nomi restano esattamente quelli di oggi.
- Livello esterno: `UNET_CHANNELS[0]` canali (64), senza cross-attention; `BATCH_SIZE` resta 128.
- Nome cartella: `<conditional|unconditional>[_smoke_test]_<IMAGE_SIZE>`.
- Test: `python -m pytest tests/` dalla cartella del progetto, senza `data/`.
- Branch: `unet-64`. Ogni commit termina con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

def test_unet_32_keeps_its_layers():
    # the same layers as before the 64x64 level: the checkpoints of the 32x32 trainings still load
    layers = {name.split('.')[0] for name in UNet(Config()).state_dict()}
    assert layers == {'time_mlp', 'conv_in', 'down1', 'downsample1', 'down2', 'downsample2', 'middle',
                      'upsample2', 'up2', 'upsample1', 'up1', 'conv_out'}


def test_unet_64_has_one_more_level():
    config = Config()
    config.IMAGE_SIZE = 64
    unet = UNet(config)
    sizes = []
    unet.middle[0].register_forward_pre_hook(lambda module, inputs: sizes.append(inputs[0].shape[-1]))
    x_t, t, context, pad_mask = make_inputs(size=64)
    assert unet(x_t, t, context, pad_mask).shape == (2, 3, 64, 64)
    assert sizes == [8]                                              # the bottom is still 8x8
    assert sum(isinstance(module, CrossAttention) for module in unet.modules()) == 5
    assert all(block.attention is None for block in [*unet.down0, *unet.up0])   # no text at 64x64


def test_unet_image_size_must_be_32_or_64():
    config = Config()
    config.IMAGE_SIZE = 48
    with pytest.raises(ValueError):
        UNet(config)

- [ ] **Step 3: modificare `UNet` in `models/unet.py`**

Docstring della classe, da:

```python
    """Three resolutions (32, 16, 8), two blocks per level, skip connections by concatenation."""
```

a:

```python
    """Two blocks per level, skip connections by concatenation, the bottom always at 8x8.

    IMAGE_SIZE = 32: three resolutions (32, 16, 8). IMAGE_SIZE = 64: the same network with one more level
    outside, at 64x64 (64, 32, 16, 8).
    """
```

In `__init__`, da:

```python
        super().__init__()
        c1, c2, c3 = config.UNET_CHANNELS          # 64, 128, 256: channels at 32x32, 16x16, 8x8
        self.base_channels = c1
        self.text_conditioning = config.TEXT_CONDITIONING
```

a:

```python
        super().__init__()
        if config.IMAGE_SIZE not in (32, 64):
            raise ValueError(f'IMAGE_SIZE must be 32 or 64, not {config.IMAGE_SIZE}')
        c1, c2, c3 = config.UNET_CHANNELS          # 64, 128, 256: channels at 32x32, 16x16, 8x8
        self.base_channels = c1
        self.text_conditioning = config.TEXT_CONDITIONING
        # 64x64: one more level outside the 32x32 network (64 -> 32), so the bottom is still 8x8, the
        # cross-attention still at 16x16 and 8x8 and every bottom pixel still sees the whole image.
        # At 32x32 its layers do not exist: the network and its checkpoints stay as they were.
        self.outer_level = config.IMAGE_SIZE == 64
```

Dopo la riga `self.conv_in = nn.Conv2d(3, c1, 3, padding=1)`:

```python
        if self.outer_level:
            self.down0 = nn.ModuleList([UNetBlock(c1, c1, config, False), UNetBlock(c1, c1, config, False)])
            self.downsample0 = nn.Conv2d(c1, c1, 3, stride=2, padding=1)                      # 64 -> 32
```

Dopo la riga `self.up1 = nn.ModuleList([UNetBlock(c2 + c1, c1, config, False), UNetBlock(c1, c1, config, False)])`:

```python
        if self.outer_level:
            self.upsample0 = nn.Sequential(nn.Upsample(scale_factor=2, mode='nearest'), nn.Conv2d(c1, c1, 3, padding=1))
            self.up0 = nn.ModuleList([UNetBlock(c1 + c1, c1, config, False), UNetBlock(c1, c1, config, False)])
```

Nella docstring di `forward`, da:

```python
            x_t: (B, 3, H, W) noisy images, H and W divisible by 4 (32 or 64).
```

a:

```python
            x_t: (B, 3, IMAGE_SIZE, IMAGE_SIZE) noisy images.
```

Nel `forward`, dopo la riga `x = self.conv_in(x_t)`:

```python
        if self.outer_level:
            for block in self.down0:
                x = block(x, time, context, pad_mask)
            skip0 = x                                                # (B, c1, 64, 64)
            x = self.downsample0(x)
```

e, alla fine, da:

```python
        for block in self.up1:
            x = block(x, time, context, pad_mask)
        return self.conv_out(x)
```

a:

```python
        for block in self.up1:
            x = block(x, time, context, pad_mask)
        if self.outer_level:
            x = torch.cat([self.upsample0(x), skip0], dim=1)         # (B, c1 + c1, 64, 64)
            for block in self.up0:
                x = block(x, time, context, pad_mask)
        return self.conv_out(x)
```

In `config.py`, da:

```python
    UNET_CHANNELS = (64, 128, 256)   # channels at 32x32, 16x16, 8x8
```

a:

```python
    UNET_CHANNELS = (64, 128, 256)   # channels at 32x32, 16x16, 8x8 (and at 64x64 when IMAGE_SIZE = 64)
```
